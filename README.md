# 🚀 Görev Paneli (Task Dashboard)

Bu proje, Software Persona staj programı kapsamında **Vue.js** ve **Tailwind CSS v4** kullanılarak geliştirilmiş modern bir görev yönetim uygulamasıdır.

## ✨ Özellikler
* **Görev Yönetimi:** Yeni görevler ekleyebilir, tarih seçebilir ve önem sırasına göre listeleyebilirsiniz.
* **Modern Arayüz:** Tailwind CSS v4 ile tamamen duyarlı (responsive) bir tasarım uygulanmıştır.
* **İlerleme Takibi:** Tamamlanan görevlerle birlikte dinamik olarak güncellenen ilerleme çubuğu.

## 🔗 Bağlantılar
* **Canlı Uygulama:** [https://ebrualtunersoftwareproject.netlify.app/](https://ebrualtunersoftwareproject.netlify.app/)
* **Geliştirici:** Ebru Ördek Altuner

## 🛠 Teknik Notlar
* **Yayın Süreci:** Uygulama Netlify üzerinden başarıyla yayınlanmıştır. 
* **SSL ve Erişim:** Alan adı değişikliği sonrası yaşanan geçici SSL sertifikası (ERR_SSL_PROTOCOL_ERROR) durumu nedeniyle, canlı uygulama şu an en sağlıklı şekilde **Opera tarayıcısı üzerinden VPN veya güvenlik duvarı istisnası** ile görüntülenebilmektedir. Projenin teknik altyapısı ve kod mimarisi eksiksizdir.
