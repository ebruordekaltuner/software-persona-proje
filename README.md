🚀 Görev Paneli (Task Dashboard)
Bu proje, Software Persona staj programı kapsamında Vue.js ve Tailwind CSS v4 kullanılarak geliştirilmiş modern bir görev yönetim uygulamasıdır.

✨ Özellikler
Görev Yönetimi: Yeni görevler ekleyebilir, tarih seçebilir ve önem sırasına göre listeleyebilirsiniz.

Modern Arayüz: Tailwind CSS v4 ile tamamen duyarlı (responsive) bir tasarım uygulanmıştır.

Canlı Yayın: Proje Netlify üzerinde yayındadır.
